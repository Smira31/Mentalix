# Нижний бар: ниже и сжатие на всех вкладках

Кадры сняты WebKit (`playwright` в web-контейнере) на демо `/?demo=1`, без
демо-рамки Telegram: 393×852 и 360×640.

- `*‑expanded.png` — верх вкладки «Сегодня», бар раскрыт на пять вкладок.
- `*‑collapsed.png` — после прокрутки вниз: бар сжат в круглую кнопку текущей
  вкладки слева, раскрывается тапом.

Проверки: `npm run ux:bottom-nav` (WebKit + Chromium). Ручной gate на iPhone —
прокрутить все пять вкладок вниз и вверх, нажать круглую кнопку, убедиться, что
конец экрана не уходит под бар. Подробности — `docs/engineering/notes/navigation.md`.
