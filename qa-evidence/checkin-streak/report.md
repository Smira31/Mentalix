# Стабильность финала чек-ина и экрана серии (fix-checkin-layout)

Прогон Chromium (Playwright), web-контейнер Base44. Вьюпорты задачи — 430×932 и 360×640.

## Что проверено

`npx playwright test --config=playwright.ux.config.mjs checkin-streak-stability.spec.mjs` — 12 тестов, 12 passed.

| Сценарий | 430×932 | 360×640 |
| --- | --- | --- |
| Утренний чек-ин: клавиатура открыта → финал → клавиатура закрыта | сдвиг 0 px (герой/заголовок/дата/CTA) | сдвиг 0 px |
| Вечерний финал: клавиатура открыта → закрыта | сдвиг 0 px | сдвиг 0 px |
| Оценка «Помогло?» на финале | сдвиг 0 px | сдвиг 0 px |
| Переход финал → серия (общий шелл) | CTA 0 px, ряд дней +25 px | CTA 0 px, ряд дней +125 px |
| Клавиатура на экране серии | сдвиг 0 px | сдвиг 0 px |
| Цветок: 1 / 3 / 5 светлых лепестков, огонёк-контур | 5 лепестков, пустой центр, без градиентов | то же |

`stable` включён на всех экранах без полей ввода: утренний финал и вечерний финал
(`CheckIn.jsx`, `stable: isCompletion` / `step === doneStep`) и экран серии
(`StreakCelebration.jsx`, `stable: true`). Тест доказывает это замером: высота шелла
равна `window.innerHeight` и при открытой, и при закрытой клавиатуре.

## Остаточные смещения

- Кнопка «Отлично!» / «Сохранить и выйти» стоит на одной высоте на финале и на экране
  серии: 0 px на обоих вьюпортах.
- Ряд дней серии по вертикали отличается от плашки даты финала (25 px на 430×932,
  125 px на 360×640). Это разное содержание экранов (цветок + ряд дней против
  иллюстрации + плашки), а не прыжок: высота неизменна в пределах своего экрана,
  блок полностью выше кнопки, прокрутки нет.
- Переход финал → серия проверен геометрией двух экранов в одном вьюпорте:
  демо-API не увеличивает серию при сохранении, поэтому автоматический показ
  экрана серии после «Сохранить и выйти» в демо-режиме не срабатывает. Код
  перехода (`exitCompletion` → `shouldCelebrateStreak`) не менялся.

## Исправления этого прогона

1. `StreakCelebration.jsx` / `.css`: фиксированный верхний отступ `max(16px, 33dvh − …)`
   заменён на центрирование `margin-block: auto` (контракт `FULLSCREEN_SCROLL_CLASS`).
   На 360×640 контент был выше области прокрутки на 28 px и обрезал ряд дней;
   теперь переполнение 0 на обоих вьюпортах.
2. `StreakGlyphs.css`: у незажжённых лепестков появился тонкий контур
   (`rgba(243,243,243,0.22)`, 0.75 px). Без него при одном светлом лепестке
   остальные четыре неразличимы и цветок читается как одиночный росток.
