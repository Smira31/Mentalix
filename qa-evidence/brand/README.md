# Иконки PWA с совой (issue #1151)

Исходник: `docs/sources/brand/owl-icon-source.jpg` (640×640, прислан владельцем).
Генератор: `scripts/generate-owl-icons.mjs` (Playwright из devDependencies, новых
зависимостей нет).

## Что сделано с кольцом

Светлое кольцо на исходнике удалено маской, без дорисовки: скрипт находит окружность
по внешней границе ярких пикселей (центр 317.83, 311.95; внешний радиус 303.17),
берёт 2-й процентиль внутреннего края по лучам (289.42) и обрезает всё от 288.67
наружу. Фон поднимается до #050403 максимумом по каналам, поэтому остаются только
пиксели совы, а вся площадь квадрата — ровный #050403 (проверено в углу: 5, 4, 3).

Следов кольца нет: за границей обрезки не остаётся ни одного его пикселя.

**Что важно знать:** в нижней части и слева сова подходит к кольцу вплотную и
перекрывает его внутреннюю сторону. Там перья заканчиваются ровно по внутреннему
краю кольца — то есть по той линии, где кольцо и начиналось. Дорисовка не
применялась. Увеличенный кадр: `owl-ring-cut-zoom.png` (слева исходник, справа
`icon-512.png`).
