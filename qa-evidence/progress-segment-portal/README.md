# Сегмент «Аналитика | История»: портал в Telegram fullscreen

Кадры 393×852 и 360×640, обе вкладки, в эмуляции Telegram fullscreen
(`?demo=1&frame=0` + hash `tgWebAppPlatform=ios`, `tgWebAppVersion=8.0`,
`tgWebAppFullscreen=1`). `before-*` сняты на `main` (строка fixed внутри
`.mx-app-scroll-root`), `after-*` — на ветке исправления (строка порталом
в `.mx-app-shell`). Попарное сравнение: визуальных отличий нет, отличие
только в родителе узла в DOM.

Скрипт съёмки — разовый, в репозиторий не входит. Пиксельная разница
Pillow: 0–20 пикселей на кадр с максимальной разницей канала 8/255
(субпиксельное сглаживание текста), сдвигов макета нет.
