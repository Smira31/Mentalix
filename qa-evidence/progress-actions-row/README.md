# Переключатель «Аналитика | История» в строке кнопок вкладки

Кадры приёмки задачи «Issue #N — Прогресс: переключатель в строке кнопок»
(ветка `move-progress-segment`, PR #1197 в `main`). Второй круг — ветка
`fix-progress-overlap`: правка перекрытия строки кнопок полосой Telegram,
PR заменяет #1197.

Съёмка: Chromium, эмуляция Telegram fullscreen без рамки
`?demo=1&frame=0&tab=trends` — рисуется демо-шапка Telegram (статус-бар,
пилюли «✕ Закрыть» и «⌄ •••»); демо-бейдж и переключатель вьюпорта скрыты
(превью-артефакты, см. комментарии в
`tests/ux/progress-segment-visibility.spec.mjs`).

Автопроверка — `npx playwright test --config=playwright.progress-segment.config.mjs`
(Chromium, demo): пять переключений вкладок подряд, `elementFromPoint` в центре
пилюли, на 360×640 и 393×852 — числовые критерии строки (края внутри полей и на
одной вертикали с карточками, допуск 1 px; зона нажатия ≥ 44×44; высоты из
одного токена; одинаковый зазор до заголовка), а также эмуляция Telegram
fullscreen: верх строки кнопок ≥ «статус-бар + 56 px», ни строка, ни заголовок не
пересекаются с пилюлями Telegram, `elementFromPoint` в центре «Аналитики» и
«Истории» — сами кнопки, при прокрутке 0 и 300 px.

Правка после первого ревью (кадры пересняты): на 360×640 во вкладке «История»
кнопка поиска выходила за правое поле (354 px при поле 344 px) — причина в
`padding-right: 3px` строки и в том, что `.mx-progress-actions-row__actions`
сжимался, а кнопки вылезали из него. Теперь правого отступа нет, кнопки не
сжимаются (`flex: none`), сжимается только сегмент до `max-content`; зазор до
заголовка одинаковый (8 px) на обеих вкладках.

Правка после второго ревью (кадры пересняты): в этой же эмуляции без рамки
демо-шапка Telegram рисовалась, а верхние инсеты задавала только рамка, поэтому
после согласования fullscreen-режима shell получал `padding-top: 0`: строка
кнопок вставала на y = 20, липкая строка прилипала к y = 0, а пилюли
«Закрыть/⋯» (y = 62…92) накрывали заголовок «история.» (y = 80…109). Замеры
после правки на 360×640 и 393×852: верх прокрутки 118 px (статус-бар 62 +
56 контролов), строка кнопок 138…190, заголовок 198…227, пилюли 62…92 —
пересечений нет; при прокрутке 300 px липкая строка стоит на 118 px, сразу под
полосой Telegram. В демо-рамке (393×852) геометрия не изменилась: 115/145/213.

Ручной gate остаётся за iPhone/Telegram: проверить, что пилюля не «исчезает»
после переключений и при прокрутке ленты «Истории» (в отчёте — NOT RUN).
