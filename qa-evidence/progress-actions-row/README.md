# Переключатель «Аналитика | История» в строке кнопок вкладки

Кадры приёмки задачи «Issue #N — Прогресс: переключатель в строке кнопок»
(ветка `progress-segment-in-actions-row`, PR в `main`, без merge).

Съёмка: Chromium, demo-режим `?demo=1&frame=0&tab=trends`, демо-бейдж и
переключатель вьюпорта скрыты (превью-артефакты, см. комментарии в
`tests/ux/progress-segment-visibility.spec.mjs`).

| Кадр                  | Что показывает                                                               |
| --------------------- | ---------------------------------------------------------------------------- |
| `393x852-analytics.png` | Слева сегмент «Аналитика \| История», справа пилюля «Недели ⌄»             |
| `393x852-history.png`   | Слева тот же сегмент, справа группировка «Дни ⌄», фильтры и поиск          |
| `360x640-analytics.png` | Узкий экран: сегмент и «Недели ⌄» в одной строке, текст не обрезан         |

Автопроверка геометрии и краски строки — `npx playwright test
--config=playwright.progress-segment.config.mjs` (Chromium, demo): пять
переключений вкладок подряд, `elementFromPoint` в центре пилюли, отсутствие
наложения и обрезки текста на 360×640.

Ручной gate остаётся за iPhone/Telegram: проверить, что пилюля не «исчезает»
после переключений и при прокрутке ленты «Истории».
