# Переключатель «Аналитика | История» в строке кнопок вкладки

Кадры приёмки задачи «Issue #N — Прогресс: переключатель в строке кнопок»
(ветка `move-progress-segment`, PR #1197 в `main`, без merge).

Съёмка: Chromium, demo-режим `?demo=1&frame=0&tab=trends`, демо-бейдж и
переключатель вьюпорта скрыты (превью-артефакты, см. комментарии в
`tests/ux/progress-segment-visibility.spec.mjs`).

| Кадр                    | Что показывает                                                          |
| ----------------------- | ----------------------------------------------------------------------- |
| `393x852-analytics.png` | Слева сегмент «Аналитика \| История», справа пилюля «Недели ⌄»          |
| `393x852-history.png`   | Слева тот же сегмент, справа группировка «Дни ⌄», фильтры и поиск       |
| `360x640-analytics.png` | 360×640: сегмент и «Недели ⌄» в одной строке, края совпадают с карточкой |
| `360x640-history.png`   | 360×640: сегмент и три кнопки «Истории» внутри полей, без обрезки текста |

Автопроверка — `npx playwright test --config=playwright.progress-segment.config.mjs`
(Chromium, demo): пять переключений вкладок подряд, `elementFromPoint` в центре
пилюли, а на 360×640 и 393×852 — числовые критерии строки: левый край сегмента
и правый край последней кнопки внутри полей и на одной вертикали с карточками
(допуск 1 px), зона нажатия каждого контрола ≥ 44×44, высоты сегмента, пилюли и
круглых кнопок из одного токена, одинаковый зазор до заголовка на обеих
вкладках.

Правка после ревью (кадры пересняты): на 360×640 во вкладке «История» кнопка
поиска выходила за правое поле (354 px при поле 344 px) — причина в
`padding-right: 3px` строки и в том, что `.mx-progress-actions-row__actions`
сжимался, а кнопки вылезали из него. Теперь правого отступа нет, кнопки не
сжимаются (`flex: none`), сжимается только сегмент до `max-content`; зазор до
заголовка одинаковый (8 px) на обеих вкладках. Замеры после правки: 360×640 —
сегмент 16…179, поиск заканчивается на 344 (= правый край карточки); 393×852 —
сегмент 16…193, последняя кнопка 377.

Ручной gate остаётся за iPhone/Telegram: проверить, что пилюля не «исчезает»
после переключений и при прокрутке ленты «Истории».
