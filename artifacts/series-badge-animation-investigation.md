# Диагностика анимации бейджа «Первый шаг»

Дата: 2026-09-21

## Факты в коде

- Экран реализован в `src/screens/SeriesBadges.jsx`.
- `RewardIcon` (строки 12–76) рисует бейдж как статичный SVG: круг `.mx-reward-icon__glass`, шаги, флаг, птица, основание. В нём нет `clip-path`, `stroke-dasharray`, SVG-анимации или изменения геометрии по времени.
- Для featured-бейджа используется `RewardIcon variant="first-step" size={128}` (строки 164–175).
- В `src/screens/SeriesBadges.css` единственная анимация появления этого блока — `.mx-path-featured-award { animation: mx-path-card-in 360ms ease-out both; }` (строка 78). Keyframes `mx-path-card-in` (строки 377–386) меняют только `opacity` и `transform: translateY(8px) → translateY(0)`.
- Строки/дуги прогресса `.mx-path-progress span` имеют только статичную ширину, без transition.
- В коде нет анимации «выезда» самого круга или прямоугольной/ступенчатой интерполяции его контура.

## Визуальная проверка

Локальный Vite-сервер был запущен на `http://127.0.0.1:5173`. Через Playwright открыт demo URL `?demo=1&tab=today`, нажата кнопка «Мой путь», после чего сняты кадры через 0, 40, 80, 120, 180, 240, 320 и 420 мс для viewport 375×812 и 390×844.

Кадры сохранены в `artifacts/series-badge-animation/frames/`.

Наблюдение: в начале экран равномерно появляется из прозрачности и с небольшим вертикальным смещением; SVG бейджа сохраняет круглую геометрию. К 120–180 мс круг, шаги, флаг и основание уже выглядят геометрически корректно; к финальному кадру форма не меняется, исчезает только остаточная прозрачность/смещение всей карточки. Ступенчатой траектории, деформации круга или неправильной интерполяции дуги в Chromium на обоих размерах не обнаружено.

## Вывод

Проблема по текущему коду и локальному Chromium не воспроизведена. Менять код наугад и открывать PR с неподтверждённым исправлением не следует. Для точной диагностики нужен короткий видеозапись/скринкаст владельца с моментом открытия бейджа, желательно с указанием устройства, OS, Telegram/Web и скорости воспроизведения.

Проверки: `npm run check:core` завершился успешно (unit, lint, build, docs:check). `npm ci` также завершился успешно, с предупреждением о несовпадении engine (проект требует Node >=22.22.1, окружение — v22.13.0). Изменений в приложении нет.
