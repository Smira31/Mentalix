# Check-In reference — финальный экран

Источник: `origin/fix/mentor-demo-preview-geometry:IMG_6255.MP4`, кадр `frame-012.png`.

Финальный экран показывает чёрный фон, белую птицу, сидящую на кольцах планеты, по центру экрана. Иллюстрация находится выше заголовка и визуально является главным акцентом. В reference присутствует `Add Tags`, но по актуальному решению пользователя эту кнопку не переносим. Промежуточные Focus и AI/Premium экраны в текущем Demo Check-In удаляются: путь должен идти от настроения и энергии прямо к записи, затем к финалу. Интерфейс и подписи — на русском.
