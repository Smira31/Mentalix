# Mentalix — задачи

- `Частично` — основа существует, требуется доводка;
- `Блокер` — работа зависит от внешнего решения или материала.

## Правило обновления

После каждой рабочей сессии:

1. обновить дату наверху;
2. перенести завершённые задачи в «Выполнено»;
3. добавить номер commit;
4. зафиксировать новые задачи и блокеры;
5. не хранить параллельный статус только в чатах.
