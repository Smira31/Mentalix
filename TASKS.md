- [ ] **MXL-PWA-ICONS — Добавить недостающие PWA-иконки**
  - `public/manifest.json` ссылается на `public/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — папка `public/icons/` пуста, все три 404. Кроме `manifest.json`, на эту папку и на сам манифест больше никто не ссылается: в `index.html` нет `<link rel="manifest">` вовсе, поэтому браузер сейчас не видит manifest.json, даже если файлы иконок появятся.
  - Минимальный набор, чтобы закрыть именно эти 404 (без изменения состава `manifest.json`):
    - `icon-192.png` — 192×192, PNG, `purpose: any`.
    - `icon-512.png` — 512×512, PNG, `purpose: any` (используется и как splash-заглушка на Android).
    - `icon-maskable-512.png` — 512×512, PNG, `purpose: maskable`; видимый рисунок должен умещаться в безопасную зону (примерно центральные 80% холста — по спецификации maskable icons OS обрезает края под свою форму маски), фон — сплошная заливка на весь квадрат до края.
  - Чтобы «Добавить на экран» реально заработало (не только закрыть 404), дополнительно нужно вне текущего набора `manifest.json`:
    - `apple-touch-icon.png` — 180×180, PNG, **без прозрачности** (iOS не читает `manifest.json` вообще, только этот файл через отдельный `<link>`); плюс сам `<link rel="apple-touch-icon" href="/apple-touch-icon.png">` в `index.html`.
    - `<link rel="manifest" href="/manifest.json">` в `index.html` — без него манифест не подключён.
  - Несостыковка на заметку: `manifest.json` использует `background_color`/`theme_color: #0E211D` (тёмно-изумрудный), а актуальный фон приложения по `DESIGN_SYSTEM.md`/`src/index.css` — `--c-bg: 0 0 0` (`#000000`). Прежде чем рисовать иконки/сплэш, стоит решить, под какой фон их готовить — иначе сплэш-экран будет видимо отличаться от реального чёрного фона приложения.
