# Mentalix — AI entry point

Перед началом работы прочитать:

1. `PRODUCT.md`
2. `DESIGN_SYSTEM.md`
3. `ARCHITECTURE.md`
4. `ROADMAP.md`
5. `TASKS.md`
6. `AI_RULES.md`

Назначение документов:

- `AI_RULES.md` — обязательный рабочий процесс;
- `PRODUCT.md` — продуктовые решения;
- `DESIGN_SYSTEM.md` — визуальные правила;
- `ARCHITECTURE.md` — технические границы;
- `ROADMAP.md` — направление развития;
- `TASKS.md` — актуальная работа;
- `CONTEXT.md` и `STOIC_FEATURES.md` — исторические документы, не source of truth.

При конфликте приоритет такой:

1. явная команда пользователя;
2. актуальный код — для фактического состояния;
3. нормативная документация — для намерений и правил;
4. исторические документы.

Перед изменением кода изучить связанные файлы. Не придумывать backend API и
не менять продуктовые решения без явного согласования. После работы выполнить
проверки, предусмотренные `AI_RULES.md`.
