# Claude Code — Mentalix

Claude Code использует те же обязательные правила, что и любой другой агент: [`AGENTS.md`](AGENTS.md). Для выбора минимального контекста, роли и следующего шага используйте [`PROJECT_BRIEF.md`](PROJECT_BRIEF.md).

Не добавляйте в этот файл отдельные процессные правила. Если правило обязательно для работы над Mentalix, оно должно быть одинаковым для всех агентов и жить в `AGENTS.md`.
