# Спецификация графа знаний Mentalix Core

**Статус:** концептуальная спецификация, не техническая база данных.

## Сущности

| Сущность | Назначение |
|---|---|
| `Problem` | наблюдаемая проблема пользователя в конкретном контексте |
| `Law` | рабочая закономерность-гипотеза Mentalix Core |
| `Principle` | нормативное правило выбора действия |
| `Model` | объясняющая карта факторов и отношений |
| `Method` | воспроизводимый способ изменения |
| `Practice` | конкретное безопасное действие или эксперимент |
| `ProductScenario` | последовательность взаимодействия пользователя с продуктом |
| `Screen` | интерфейсная поверхность сценария |
| `Source` | книга, заметки, исследование, наблюдение или иной материал |
| `Evidence` | конкретное свидетельство за, против или в границах гипотезы |
| `Risk` | возможный вред, ошибка применения или ограничение |
| `Metric` | способ наблюдать результат и побочные эффекты |
| `Decision` | зафиксированное архитектурное или методологическое решение |

## Допустимые связи

```text
Source supports Law
Source limits Law
Source contradicts Law
Problem uses Law
Law produces Model
Model produces Method
Method produces Practice
Practice appears in ProductScenario
ProductScenario appears on Screen
Practice measured by Metric
Law has Risk
Decision references Law
```

Связь не подразумевает доказанную причинность. У неё должны быть статус, основание и дата проверки. `supports` означает только заявленную степень поддержки, а не универсальное подтверждение.

## Минимальный пример

**Problem:** «Знаю, что делать, но не начинаю».

**Связанные Law:** `MXL-L001`, `MXL-L002`, `MXL-L005`, `MXL-L015`.

**Method:** уменьшить следующий шаг и изменить условия старта.

**Practice:** «Первый шаг за пять минут» — кандидат, не принята.

**ProductScenario:** экран «Сегодня» предлагает один конкретный следующий шаг. Это возможная реализация; соответствие текущего экрана Core ещё не проверено.

**Source:** сверенные методологические разборы книг Тима Гровера, Шари Уэнк и Андрея Курпатова из [`../methodology/books/`](../methodology/books/). Связь с книгой означает происхождение гипотезы, но не заменяет независимую научную проверку каждого звена.

**Metric:** время до первого действия, доля начатых шагов, субъективное напряжение до и после.

**Risk:** микрошаг не должен маскировать болезнь, истощение, опасность или объективную нехватку ресурсов.

## Минимальные требования к узлу

Каждый узел должен иметь стабильный ID, статус, формулировку, происхождение, дату последней проверки и владельца. Каждая значимая связь должна указывать основание, ограничение и способ опровержения.
