## 3. Мягкая серия — frontend в работе

Решение владельца 27.09: любая завершённая активность учитывается backend, один пропуск в календарную неделю не обрывает серию. Gate: backend `feat/soft-streak`, проверка демо-сценариев с заморозкой и восстановлением, ручная проверка на iPhone. `docs/STATUS.md` не менять.
