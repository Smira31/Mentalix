## 3. Мягкая серия — frontend в работе

Решение владельца 27.09: любая завершённая активность учитывается backend, один пропуск в календарную неделю не обрывает серию. Фронт берёт серию из `GET /api/streak`; при отсутствии новых булевых полей скрывает заморозку и восстановление. Отображение конкретной даты заморозки требует отдельного поля в backend-контракте. Gate: backend `feat/soft-streak`, проверка демо-сценариев с заморозкой и восстановлением, ручная проверка на iPhone. `docs/STATUS.md` не менять.
