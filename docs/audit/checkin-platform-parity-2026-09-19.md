# Диагностика расхождения PWA / Telegram Check-in

Дата: 2026-09-19

## Вывод

Расхождение не похоже на разные ветки или разные React-сборки. В одной кодовой базе `src/screens/CheckIn.jsx` есть два параллельных компонента:

- `DemoCheckInFlow` — preview/PWA-вариант, который включается через `isPreviewDemoMode()` для `?demo=1` или `?source=pwa` на разрешённых preview/demo-хостах. Сейчас в нём только три вопроса: самочувствие, энергия и текстовая запись.
- `CheckInCore` — основной flow, который используется вне preview/demo-режима, включая Telegram. В нём полный набор: шкалы `mood`, `energy`, `anxiety`, `focus`, затем emotion chips и текстовая запись.

Выбор сделан runtime-предикатом `isPreviewDemoMode()`, а не разными ветками. `platformName` определяет web/Telegram адаптер (`src/platform/index.js`), но сам по себе не выбирает отдельную сборку чек-ина. Поэтому причина — два параллельных компонента внутри одной кодовой базы, а не подтверждённый deployment drift.

## Тестовый контекст

Playwright поднимает локальный Vite dev/preview server. В unit-тестах Telegram эмулируется через `window.Telegram.WebApp.initData`; отдельного полного PWA-vs-Telegram скриншотного теста для шести вопросов пока нет. Реальный Telegram WebView в текущем наборе тестов не используется.

## Решение этого PR

- Целевой набор: шесть вопросов в порядке Telegram: энергия, самочувствие-эмодзи, собранность, шум в голове, emotion chips («что ближе всего?»), текстовый вопрос.
- Вопросы-шкалы получают PWA-стиль: градиентные кружки без цифр, подписи только по краям.
- Completion-экран и кнопки текстового ввода в этот PR не меняются.
- После фикса PWA и Telegram должны использовать один React-компонент вопроса.

## Решения владельца

1. Счётчик `ЧЕК-ИН · X ИЗ 6` и точки прогресса не нужны. Они удалены из общей CheckIn-шапки, поэтому не рендерятся ни в PWA, ни в Telegram.
2. Для вопроса о самочувствии используется текст «Как ты сейчас?». Дополнительных изменений текста не требуется.
3. Расхождения completion-экрана остаются отдельной задачей.
4. Расхождения кнопок текстового ввода остаются отдельной задачей.
