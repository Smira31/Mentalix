### 3.1. SHA drift в четырёх документах

Рекомендация: сохранить один исторический pre-merge inventory и один актуальный короткий каталог статусов; остальные архивировать.

### 3.3. BackButton и закрытые PR

После PR #738/#741 и закрытия коллекций эти документы нельзя считать независимыми текущими списками. Рекомендация: оставить `BACKBUTTON_AUDIT.md` как основной navigation audit, а fullscreen-документ архивировать или сократить до визуального контракта доступных flow.

## 7. Границы и нерешённые вопросы

Этот PR не исправляет ни один исходный документ, не удаляет мёртвые source-файлы и не меняет product availability. Наличие `Focus.jsx`, `MeditationFlow.jsx`, `Breathing.jsx`, `BrainTrainer.jsx` и старых psychological-flow файлов в `src/` отмечено отдельно, потому что после #743 это dead/retained code boundary, а не доказательство доступности.

Не следует автоматически считать stale формулировки в историческом `CHANGES.md` ошибками: для них важны дата записи и исторический контекст. В отчёте выделены только случаи, где документ имеет `current`/`draft` роль либо явно использует старый статус как основание текущей рекомендации.

PR #742 намеренно не классифицирован как закрытый: GitHub API показывает его открытым. Issue #647 и #480 также намеренно оставлены открытыми в findings, поскольку GitHub подтверждает их открытое состояние.
