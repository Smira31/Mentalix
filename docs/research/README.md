# Пользовательские исследования Mentalix

**Статус:** рабочий стандарт v0.1.

Эта папка хранит протоколы, обезличенные сводки и решения. Она не предназначена для аудио, видео, контактов, медицинских сведений или полных личных историй участников.

## Базовые правила

1. До разговора человек получает цель, длительность, формат, возможный дискомфорт, способ использования данных и право прекратить участие без последствий.
2. Участие добровольное; согласие спрашивается до начала и повторно перед записью, если запись вообще необходима.
3. По умолчанию интервью не записывается. Исследователь ведёт минимальные заметки.
4. Используется код `P01`–`P05`; имя, телефон, username и другие прямые идентификаторы не попадают в репозиторий.
5. Фиксируются только данные, необходимые для исследовательского вопроса. Чувствительные подробности заменяются нейтральным описанием контекста.
6. Участник может не отвечать на любой вопрос и попросить удалить свои необобщённые заметки до синтеза.
7. Интервью не является терапией, диагностикой или экстренной помощью. Модератор не интерпретирует состояние и не даёт медицинских советов.
8. При выраженном дистрессе разговор останавливается; безопасность важнее заполнения сценария.
9. В Git фиксируются только агрегированные наблюдения, короткие обезличенные фрагменты и решения методологии.
10. Перед реальным набором проверяются применимые требования к согласию, хранению и удалению данных в юрисдикции продукта и участников.

## Разделение этапов

```text
проблемное интервью
→ синтез языка и барьеров
→ решение о карточке проблемы
→ отдельный тест практики
→ решение о продуктовом сценарии
```

Проблемное интервью не должно одновременно доказывать эффективность решения. Концепт практики показывается только после основных вопросов и анализируется отдельно либо не показывается вовсе.

## Источники правил

- [HHS OHRP: Informed Consent FAQs](https://www.hhs.gov/ohrp/regulations-and-policy/guidance/faq/informed-consent/index.html) — понятность информации, добровольность, описание рисков и право прекратить участие.
- [GDPR, Article 5](https://eur-lex.europa.eu/eli/reg/2016/679/2016-05-04/eng) — ограничение данных заявленной целью, минимизация и ограничение срока хранения.

Ссылки задают консервативный ориентир, но не являются юридическим заключением о конкретном исследовании Mentalix.
