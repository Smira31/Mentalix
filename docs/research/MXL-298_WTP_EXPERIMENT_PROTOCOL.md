# MXL-298 — Willingness-to-pay experiment protocol

This is a no-checkout fake-door/concept test. The free daily loop remains fully usable and the test does not collect payment credentials.

| Concept | Promise to test | Trust question |
| --- | --- | --- |
| Extended problem-led track | more structured progress for one problem | does the outcome feel concrete? |
| Personal pattern summary | cautious summary of accumulated history | is provenance and privacy understandable? |
| Explicit AI deepen | optional deeper analysis after a completed action | does consent feel meaningful? |

Ask participants to explain what they think they would receive, rate value and trust, choose whether they would continue, and name an objection. Record conversion intent, perceived value and objection separately; intent is not payment or retention. Stop if users believe the feature is therapy, guaranteed improvement, hidden memory or required for the free loop.

Evidence requires at least the same script, randomized concept order, participant context, quotes and unresolved objections. No provider, price, checkout or paywall decision is made by this document.
