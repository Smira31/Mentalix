# Шаблон заметки проблемного интервью

Не добавлять заполненные персональные заметки в публичный репозиторий. В Git попадает только обезличенная сводка пяти интервью.

## Паспорт

- **Исследование:** `MXL-RSCH-001`
- **Код участника:** `P0X`
- **Дата:**
- **Согласие на участие:** да / нет
- **Согласие на обезличенную сводку:** да / нет
- **Запись:** нет / отдельное согласие получено
- **Интервью завершено:** да / остановлено участником / остановлено по безопасности

## Недавний случай

- контекст без личных деталей;
- задача в обобщённой форме;
- ожидаемое время старта;
- что произошло вместо старта;
- наблюдаемое первое действие.

## Язык участника

До трёх коротких обезличенных формулировок. Не сохранять имена, места работы, диагнозы и сведения о третьих лицах.

## Барьеры

- барьер, названный участником;
- наблюдаемые обстоятельства;
- интерпретация участника;
- соответствует текущей карте / новый / противоречит карте;
- уверенность исследователя: низкая / средняя / высокая.

## Предыдущие попытки

- что помогало;
- что не помогало;
- что усиливало давление;
- когда малый шаг был бы неуместен.

## Критерий старта

- какой факт означает «начал»;
- нужно ли продолжение;
- желаемый результат без давления.

## Наблюдения исследователя

- что является фактом разговора;
- что является интерпретацией;
- какой вопрос мог быть наводящим;
- что нужно изменить в следующем интервью.

## Для синтеза

- основная категория;
- новый барьер-кандидат;
- противоречащий случай;
- риск или ограничение;
- решение об удалении необобщённых заметок и срок.
