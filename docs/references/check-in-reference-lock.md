## Жёсткие ограничения

Reference является главным источником композиции. Нельзя добавлять новые этапы, AI/Premium-вкладки, карточки или альтернативные CTA. Разрешено менять только язык текста: английский reference переводится на русский без изменения смысла. Production не затрагивается.
