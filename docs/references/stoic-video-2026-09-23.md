## Масштаб

1 pt Stoic = **1,5 px** кадра. Проверено по статус-бару iOS: высота цифр
времени 18 px = 12 pt (SF Pro 17 pt). Ширина кадра 590 px = 393 pt — та же
эталонная ширина, что в §5.1. Размеры в документах даны в pt = CSS px.

## Замеры движения (по кадрам 60 fps)

| Переход                    | Что происходит                                                                                                                               | Длительность                                     |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| «Начать» → чек-ин          | чёрный экран въезжает снизу и закрывает «Сегодня»; вопрос и шкала доезжают вверх с замедлением; «Пропустить» и «далее» появляются последними | покрытие 170 ms; контент до 500 ms; низ с 370 ms |
| Чип серии → шторка         | шторка въезжает снизу, лёгкая доводка без заметного перелёта                                                                                 | 270 ms + ~150 ms доводка                         |
| Шаг → шаг внутри флоу      | горизонтальный сдвиг: текущий экран уходит влево, следующий приходит справа                                                                  | ~300 ms                                          |
| Тап по лицу в «Настроении» | лицо подсвечивается, затем автопереход к эмоциям                                                                                             | ~150 ms до перехода                              |
| Завершение (появление)     | иллюстрация и заголовок сразу; вопрос, кнопки отзыва и «Сохранить» — позже                                                                   | задержка 500 ms, появление 300 ms                |
| «Сохранить» → «Сегодня»    | экран уезжает вниз; карточка дня одновременно меняет состояние и сжимается                                                                   | уход 170 ms; смена карточки 130 ms               |
| Пауза → «Новый значок»     | фон затемняется, шторка въезжает снизу                                                                                                       | пауза 400 ms; въезд 250 ms                       |

Точность — ±1 кадр при 30 fps (±33 ms).
