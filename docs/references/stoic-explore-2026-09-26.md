# Stoic Explore — референс для экрана «Шаги»

Дата: 2026-09-26
Решение владельца: главный экран вкладки «Шаги» — как Explore у Stoic.

## Источник

Приложение Stoic (iOS), экран Explore. Геометрия и композиция переносятся
по правилам DESIGN_SYSTEM.md §5.1 (что берём / что не берём). Тексты —
только свои, на русском языке.

## Структура экрана сверху вниз

### 1. Шапка

- Слева крупно **«шаги.»** — жирный строчный с точкой (`.mx-type-page`,
  `font-display`, `lowercase`).
- Справа круглая кнопка поиска **43×43 px** — фильтр практик и тем по
  названию. Фон `--c-card2`, рамка 1 px `--c-border`, иконка Search 20 px.

### 2. Герой-карточка

- Слева — иллюстрация (переиспользовать `JournalArt` или
  `SemanticGlyph`).
- Справа:
  - мелкая подпись-повод (`.mx-type-meta`, `font-label`, `text-muted`);
  - жирный заголовок (`.mx-type-card` или крупнее, `text-cream`);
  - 3–4 строки описания (`.mx-type-body`, `text-muted`);
  - справа внизу светлая пилюля **«Начать ›»** — рекомендованная практика
    или журнал (сейчас «Разбери день на части» — Guided Self-Discovery,
    `sub: 'journal'`).
- Поверхность: `--c-card2`, радиус `--mx-radius-hero` (32 px), без рамки.

### 3. Сетка практик — 2 колонки

Карточки практик в сетке 2 колонки, зазор 8 px:

- Иконка (SemanticGlyph / PracticeGlyph).
- Метка капсом: **«НОВОЕ»** (фиолетовая плашка) или **«РЕКОМЕНДУЕМ**.
- Мелкая категория (`.mx-type-meta`, `font-label`, `text-muted`).
- Жирное название (`.mx-type-card`, `text-cream`).
- Серое описание (`.mx-type-body`, `text-muted`), 1–2 строки.
- Справа вверху кнопка **«…»** → меню:
  - **Открыть** — запускает практику.
  - **В избранное** — закрепить на «Сегодня» (существующий API
    `pinnedPractices.add`); гостю не показывать.
  - **Поделиться** — если есть в SDK (Telegram `shareMessage`).
  - **Показывать реже** — скрыть карточку, хранить список скрытых на
    устройстве (`localStorage`).

### 4. Чек-ин эмоций

- Блок на тёмном фоне (`--c-card` или темнее) с силуэтом головы
  (переиспользовать визуальный элемент из «Диалога» — PersonaPicker).
- Заголовок: **«ЧЕК-ИН ЭМОЦИЙ»** (caps, `font-label`).
- Подзаголовок: **«Как бы ты описал свои чувства?»** (`.mx-type-section`,
  `text-cream`).
- Пилюля **«Начать»** → практика «Настроение» (`sub: 'mood'`).

### 5. Тема недели

- Заголовок: **«Тема недели: \<название\>.»** — **шрифт с засечками**
  (`--font-serif`, Lora), `.mx-type-section`, `text-cream`.
- Горизонтальная карусель карточек-вопросов:
  - крупная цифра (номер дня);
  - текст вопроса;
  - точки-индикаторы (пагинация карусели);
  - пилюля **«Начать запись»** → экран темы (`onOpenTheme`).
- Данные: `themes[0]` (текущая неделя, `is_current: true`), поле `days[]`.

### 6. Другие темы

- Заголовок: **«Другие темы»** — **шрифт с засечками** (`--font-serif`).
- Карточки тем:
  - название строчными с точкой;
  - строка описания;
  - тонкая полоска прогресса (`reflected_days` / `total_days`);
  - шеврон (ChevronRight).
- Пилюля **«⤨ Удиви меня»** — случайная непройденная тема (где
  `reflected_days < total_days`).

### 7. Все темы

- Заголовок: **«Все темы»** — **шрифт с засечками** (`--font-serif`).
- Чипы-фильтры: **Все / Пройдены / В процессе / Не начаты**.
  - Пройдены: `reflected_days >= total_days`.
  - В процессе: `0 < reflected_days < total_days`.
  - Не начаты: `reflected_days === 0`.
- Пустое состояние: иллюстрация, **«Здесь пока пусто»**, **«Выбери тему
  и пройди её до конца — она появится здесь»**.

### 8. Экран темы

- Круглая кнопка **«Назад»** (43×43, `mx-nested-screen-back`).
- Заголовок темы.
- Карусель вопросов (крупная цифра, текст).
- Пилюля **«Начать запись»** / **«Посмотреть в истории»**.
- Переиспользовать существующий `ThemeScreen.jsx`.

## Шрифт

Заголовки разделов «Тема недели: …», «Другие темы», «Все темы» — **с
засечками**, как у Stoic: токен `--font-serif` (Google Fonts с кириллицей —
Lora, не Georgia). Только для этих заголовков. Остальное — основной шрифт
(Onest).

Правило зафиксировано в DESIGN_SYSTEM.md §3.

## Данные и API

- **Темы**: `api.themes.list` (массив с `id`, `title`, `subtitle`,
  `total_days`, `reflected_days`, `is_current`) + `api.themes.get`
  (детали с `days[]`). Кеш — `themesDataCache.js` (TTL 30с).
- **Практики**: `buildPracticeViewModels` из `practiceCatalogRegistry.js`
  + `practicesDataCache.js` (ритуалы/аскезы).
- **Закреплённые**: `api.pinnedPractices.list` / `add` / `remove`.
- **Прогресс тем**: `reflected_days` / `total_days` из `themes.list`.
  Чего нет в API — описано в отчёте; бэкенд не меняется.

## Демо

- `isPreviewDemoMode()` — все блоки с демо-данными.
- `&empty=1` — пустые состояния (нет тем, нет практик).
- Новые API-вызовы — заглушки в `tests/ux/ux-check.spec.mjs` (`fixtureFor`).
- `demoMode.js` — только добавления.
