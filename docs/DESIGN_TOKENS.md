# Дизайн-токены Mentalix

Токены живут в `src/index.css` (`:root`). Все новые экраны и компоненты
используют только токены — локальные пиксельные значения запрещены
(см. правило в `AGENTS.md`).

## Отступы (spacing)

| Токен             | Значение | Где используется                          |
|-------------------|----------|-------------------------------------------|
| `--mx-space-1`    | 4px      | микро-зазоры, gaps чипов                   |
| `--mx-space-2`    | 8px      | отступы внутри карточек, gaps              |
| `--mx-space-3`    | 12px     | отступ заголовка от подсказки              |
| `--mx-space-4`    | 16px     | боковые отступы экрана (`--mx-screen-x`)   |
| `--mx-space-5`    | 20px     | отступ шапки от контента                   |
| `--mx-space-6`    | 24px     | отступ секций, padding кнопок              |
| `--mx-space-7`    | 28px     | отступ вопроса от прогресса                |
| `--mx-space-8`    | 32px     | крупные секционные отступы                 |
| `--mx-space-10`   | 40px     | отступ между секциями                      |
| `--mx-space-12`   | 48px     | максимальный ритмический отступ            |

## Радиусы

| Токен               | Значение | Где используется                     |
|---------------------|----------|--------------------------------------|
| `--mx-radius-xs`    | 14px     | мелкие контролы, чипы                |
| `--mx-radius-control` | 16px   | контролы, инпуты                     |
| `--mx-radius-md`    | 20px     | средние карточки                     |
| `--mx-radius-card`  | 24px     | стандартная карточка                 |
| `--mx-radius-lg`    | 28px     | крупные карточки                     |
| `--mx-radius-hero`  | 32px     | hero-карточки, баннеры               |
| `--mx-radius-pill`  | 999px    | кнопки-пилюли, чипы                  |

## Высоты кнопок

| Токен             | Значение | Где используется                         |
|-------------------|----------|------------------------------------------|
| `--mx-btn-pill-h`  | 54px     | `<PillButton>`, CTA-пилюли               |
| `--mx-btn-round-h` | 45px     | `<RoundNextButton>`, круглая отправка    |
| `--mx-btn-glass-h` | 49px     | `<GlassButton>`, стеклянная кнопка       |

## Геометрия экрана

| Токен            | Значение                          | Где используется                |
|------------------|-----------------------------------|---------------------------------|
| `--mx-screen-top` | `safe-top + 56 + 16`             | верхний отступ под шапкой Telegram |
| `--mx-screen-x`  | 16px                              | боковые отступы контента экрана  |
| `--app-safe-bottom` | `max(env, tg-safe)`             | нижний safe-area отступ          |

|-------------|-------------|---------|------------------------------|
| `--c-bg`    | 5 4 3       | #050403 | основной фон приложения       |
| `--c-card`  | 9 9 9       | #090909 | карточки                     |

| `--c-gold`  | 224 224 224 | #E0E0E0 | нейтральный акцент            |
