# Архив документации Mentalix

> Архив хранит доказательства прошлых решений, проверок, исследований и handoff. Он **не является** текущим backlog, release snapshot или набором обязательных инструкций для нового агента.

Перед новой работой используйте [`../../PROJECT_BRIEF.md`](../../PROJECT_BRIEF.md), [`../../AGENTS.md`](../../AGENTS.md), [`../TASK_INDEX.md`](../TASK_INDEX.md) и конкретный GitHub Issue/PR. Открывайте файл из этого каталога только для ответа на конкретный исторический вопрос.

| Раздел                | Содержание                                                              |
| --------------------- | ----------------------------------------------------------------------- |
| `audits/`             | Датированные аудиты интерфейса и документации.                          |
| `handoffs/`           | Снимки завершённых диалогов и прежних рабочих передач.                  |
| `ui/`                 | Закрытые UI-планы, mapping и pre-mortem.                                |
| Корневые legacy-файлы | Более ранние материалы, сохранённые без ретроспективного переписывания. |

Исторические материалы не обновляются для текущего статуса. Новый факт попадает в связанный Issue/PR, `docs/TASK_INDEX.md` или `PROJECT_STATE.md` согласно назначению источника.
