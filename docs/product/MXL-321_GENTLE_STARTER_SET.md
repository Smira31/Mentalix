# MXL-321 — Gentle starter set

## Starter contract

At first entry, offer one context choice from **focus, calm, energy, order, self-understanding**. Show three suggestions with purpose, duration and an easier version. The user may accept, skip, replace or edit each suggestion. The first cycle contains at most one practice and one voluntary abstention; nothing is mandatory.

| Surface | Required copy/behavior | Guardrail |
| --- | --- | --- |
| Context choice | explain why suggestions differ | no personality inference |
| Suggestion | purpose + light version + duration | no medical or moral claim |
| Today | one main next step | no catalogue overload |
| Evening review | keep, simplify, change or remove | no penalty for skipping |

Success is measured by time to first choice, comprehension of voluntariness, edit/skip rate, first-step completion and return intent. The starter set must be removable and must not change persistence or backend contracts.
