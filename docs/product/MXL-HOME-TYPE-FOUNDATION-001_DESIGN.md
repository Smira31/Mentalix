# MXL-HOME-TYPE-FOUNDATION-001 — тихий Home и единая типографика

## Статус

**In progress.** Это рабочая продуктовая фиксация для solo-разработки. Она не копирует бренд, proprietary assets или proprietary font Stoic; переносится только общий принцип спокойного ежедневного входа.

## Решение

Главный экран Mentalix должен сначала показывать человеку состояние дня и один следующий шаг, а не весь каталог функций. Home сохраняет существующие Today, Practices, Наставник, Библиотеку и Тренды, но визуально подчиняет их одной иерархии.

Journal остаётся четырёхфазным циклом «Идея → Действие → Анализ → Новый шаг». Вкладка «Наставник» остаётся отдельным пространством для более глубокого разбора и открывается как optional action, а не автоматически.

## Home hierarchy

1. Спокойный greeting и короткий weekly rhythm.
2. Одна главная карточка состояния дня с одним CTA.
3. Вторичные блоки: практики, тема недели, journal и прогресс.
4. Тихая нижняя навигация без конкурирующих CTA.

## Типографика

Onest закрепляется как единый `font-body` и `font-display` для пользовательских экранов. Различие между заголовком, body и meta создаётся размером, весом, line-height и цветом. Локальные `Georgia`, `Times New Roman` и другие display overrides не используются в Journal/Home.

## Definition of done

Home не показывает несколько равноправных главных действий, русский текст использует единый Onest baseline, главный hero-блок идёт до вторичных блоков, нижняя навигация не перекрывает контент, а версии 320×568 и 390×844 не создают случайный горизонтальный overflow.

## Не входит в этот slice

Backend, cloud sync, AI consent, новая навигационная вкладка, tags, search, media, streak competition и pixel-perfect копирование Stoic.
