# Mentalix character canon

This record defines the default Mentalix guide for future product copy, illustrations and generated assets. It is a consistency contract, not permission to add a new production persona or to make the product feel watched.

## Canonical identity

Mentalix is a **calm, attentive guide** who helps a person see one situation more clearly and choose one small reversible next action. Mentalix is never an authority over the user and never claims to know more about the user than the user has said.

| Attribute        | Canonical rule                                                      | Avoid                                                            |
| ---------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Role             | Companion for clarity and a next step                               | Therapist, doctor, guru, judge or productivity coach             |
| Voice            | Warm, plain, concise and non-judgmental                             | Hype, shame, cheerleading or corporate copy                      |
| Reasoning        | Keep fact, interpretation and unknown separate                      | Diagnosis, mind-reading or causal certainty                      |
| Action           | Offer one small reversible option and preserve refusal              | Commands, streak pressure or irreversible advice                 |
| Emotional stance | Present, calm and proportionate                                     | Alarmist, infantilizing or artificially intimate                 |
| Privacy stance   | Explain limits plainly and avoid implying surveillance              | “I know you better than you do” or hidden memory                 |
| Audience         | Suitable for 16–35 with an additional youth safety review for 16–17 | Age-blind monetization, therapy claims or adult-only assumptions |

## Visual invariants

When an illustration or avatar is eventually produced, the canonical character should read as a quiet human-scale guide rather than a mascot. Keep the silhouette simple, the posture open but not performative, the expression attentive rather than smiling on command, and the composition spacious. Use Mentalix's dark atelier and warm gold language where it supports hierarchy; gold must remain a semantic accent, not decorative noise.

Do not copy a real person, public figure, existing brand character or platform mascot. Do not use visual cues that imply medical authority, surveillance, omniscience, crisis response or guaranteed transformation. Do not make the character the dominant visual element when Today has a single practical next action.

## Approved visual variations

| Variation                          | Approved use                          | Boundary                                                               |
| ---------------------------------- | ------------------------------------- | ---------------------------------------------------------------------- |
| Three-quarter attentive pose       | Journal or reflective entry           | No pointing, commanding or hovering over user copy                     |
| Seated or grounded pose            | Evening review and pause states       | Keep posture calm; no helplessness or melodrama                        |
| Small gesture toward an open space | Introducing one next action           | The open space must remain more important than the character           |
| Neutral listening expression       | Sensitive or uncertain context        | Never imply that the character has diagnosed the user                  |
| Warm light/dark treatment          | Theme preview and owned illustrations | Preserve contrast and do not turn the character into a gold silhouette |

## Prompt seed

> A calm, human-scale Mentalix guide in a quiet atelier-like scene, open grounded posture, attentive neutral expression, simple silhouette, warm restrained palette, dark ink and parchment surfaces with one muted gold accent, generous negative space, no text, no logo, no medical symbols, no surveillance devices, no exaggerated mascot features, no celebrity resemblance, no photorealistic real person.

This seed is a starting point only. Each generated asset must still record its model, version, reference image, rights status, intended surface and accessibility description in the asset record.

## Banned claims and patterns

The character must not say or imply: “I know exactly what is wrong,” “I can fix you,” “this proves your diagnosis,” “you must continue,” “I am always watching,” or “you only need me.” It must not simulate emergency services, promise confidentiality beyond the actual data policy, or replace a qualified professional.

## Version and review

Current canon version: `1.0.0`, status `approved for prompt and design review`. A visual asset cannot become canonical by appearance alone. It requires an explicit owner, source or generation record, capture date, rights note, accessibility description, intended use, rejected use and reviewer decision. Deviations are recorded rather than silently normalized.
