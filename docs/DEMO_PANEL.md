# Демо-панель

В веб-демо `?demo=1&panel=1` открывает нижнюю шторку; также её открывают удержанием приветствия на «Сегодня» в течение секунды и нажатием на бейдж в углу. В Telegram и без демо компонент не загружается. Закрытие — крестик или свайп вниз по заголовку.

- **Машина времени:** четыре времени, сдвиг ±1 день и возврат к реальному времени. `src/lib/clock.js` хранит выбор в `sessionStorage`; production возвращает обычный `Date`.
- **Готовые аккаунты:** сценарии в `src/lib/demoMode.js`; смена очищает демо-снимок и перезагружает экран. Действия записываются в версионированный ключ `localStorage`, изолированный от настоящих пользователей.
- **Сеть:** задержка 4 с, ошибка сети либо 503 применяются в демо-ответах до записи действия.
- **Референс:** кадры из `docs/references/stoic-video-2026-09-23/` и `docs/references/checkin-screenshots/` выбираются из списка; собственное изображение с телефона отображается только в текущей вкладке через временный URL, никуда не загружается и исчезает после перезагрузки. Ползунок управляет прозрачностью; наложение не перехватывает касания.

Проверка: `npm run test:unit` и `npm run ux:check` (тест `demo-panel.spec.mjs`, телефон 440×956).
