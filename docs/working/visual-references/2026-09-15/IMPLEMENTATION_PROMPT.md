# Mentalix — визуальный контракт Today / Огонёк / Настройки

Работай в актуальной ветке Mentalix отдельной визуальной итерацией. Цель — перенести приложенные PNG-референсы в реальный Demo Preview. Сначала проверь текущий HEAD и живые `.jsx`-экраны; не редактируй устаревшие `.tsx`-дубли.

## Источники истины

- `01-today-before.png` — текущий полный экран Today.
- `02-today-after.png` — целевой полный экран Today с новой шапкой и календарём.
- `03-streak-before.png` — текущий полный экран серии.
- `04-awards-after.png` — целевая вкладка «Награды».
- `05-stats-after.png` — целевая вкладка «Статистика».
- `06-settings-before.png` — текущие настройки.
- `07-settings-after.png` — целевые настройки.

Все семь файлов — полноэкранные PNG размером `1320×2868`, то есть физический viewport iPhone 16 Pro Max. PNG определяют композицию, размеры, safe-area, ритм, иерархию, цвет и форму компонентов. Текущий код и данные определяют реальные функции, значения, навигацию и доступность. Не растягивай отдельный фрагмент на экран и не интерпретируй PNG как абстрактный moodboard.

## 1. Today: шапка и календарь

Перестрой только верхнюю область Today по полному экрану `02-today-after.png`; всё ниже календаря сохрани по текущему экрану `01-today-before.png`:

- по центру — «добрый вечер.»;
- слева — компактный счётчик серии с огоньком и числом;
- справа — круглая кнопка профиля вместо шестерёнки;
- ниже — семь равномерных колонок недели;
- выбранный день выделяется высокой нейтральной скруглённой рамкой;
- у понедельника нет галочки и вообще нет отдельного индикатора выполнения;
- огонёк, число, профиль, рамка выбранного дня и все активные элементы серо-белые;
- в этой области запрещены синий, голубой и золотой акценты.

Не менять содержимое карточек Today ниже календаря и не менять их продуктовую логику.

## 2. Огонёк: fullscreen «Награды / Статистика»

Тап по огоньку открывает fullscreen-поверхность через существующий `useFullscreenSurface`.

Общие правила:

- закреплённая шапка;
- сегменты «Награды» и «Статистика»;
- круглая кнопка закрытия;
- нижней навигации внутри fullscreen нет;
- прокручивается только содержимое под шапкой;
- никаких fade/scale/translate-вспышек при открытии и закрытии;
- вся палитра серо-белая и угольно-чёрная, без синего и золота.

### Награды

Повтори `04-awards-after.png`:

- крупная карточка последней открытой награды;
- заголовок «1 награда открыта» и «Первый шаг»;
- ниже список «Следующие награды»;
- каждая строка содержит монохромную иллюстрацию, название, пояснение, дробное значение и тонкий progress bar;
- карточки и интервалы должны совпадать с PNG, но значения берутся из текущих данных приложения.

### Статистика

Повтори `05-stats-after.png`:

- две верхние сводные карточки;
- секции «Рекорды», «Общее», «Дневник», «Осознанность», «Настроение»;
- названия слева, значения справа;
- тонкие разделители без отдельных карточек для каждой строки;
- русский текст из PNG;
- использовать существующие реальные данные и текущие вычисления;
- отсутствующие показатели показывать как `0`, но не придумывать новый backend/API.

## 3. Настройки

Тап по круглой кнопке профиля открывает fullscreen-настройки по `07-settings-after.png`:

- закреплённая полупрозрачная шапка;
- подарок слева, «твой профиль.» по центру, закрытие справа;
- премиальная карточка и карточка подарка;
- секции «Персонализация», «Аккаунт», «Сообщество», «Помощь и поддержка», «Приложение»;
- строки собраны в группы с одной внешней оболочкой и тонкими разделителями;
- существующие настройки, переключатели, ссылки и действия сохранить — меняется представление, а не продуктовая логика;
- не добавлять несуществующую оплату, API или backend-контракты;
- русский интерфейс без английских строк.

## Запреты

- Не копировать название, логотипы или бренд исходного приложения-референса.
- Не вводить новые дизайн-токены и зависимости.
- Не менять Mentor, Check-In, Journal, Progress и Library.
- Не менять API, авторизацию, privacy/security и модель данных.
- Не выполнять merge и не менять production без отдельного подтверждения владельца.
- Не публиковать промежуточную реализацию в production.

## Порядок и проверка

1. Реализуй все три области в одной ветке, но коммить логическими блоками: Today; Огонёк; Настройки.
2. Запусти `npm run build` и только точечные проверки затронутых маршрутов.
3. Подготовь screenshots iPhone 16 Pro и Pro Max для четырёх состояний: Today, Награды, Статистика, Настройки.
4. Опубликуй READY immutable Preview и обнови только `mentalix-preview.vercel.app`.
5. Сообщи полный HEAD SHA, Deployment ID, HTTP 200 и ссылку Demo Preview.
6. Остановись и жди ручного визуального PASS владельца. Production и merge — только отдельной командой после PASS.
