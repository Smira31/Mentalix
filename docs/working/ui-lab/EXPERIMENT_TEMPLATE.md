# `UI-EXP-NNN` — название эксперимента

- **Дата начала:** YYYY-MM-DD
- **Владелец / scope:** кто и какую часть UI проверяет
- **Проблема:** какое наблюдаемое затруднение проверяем
- **Гипотеза:** если ..., то ..., потому что ...
- **Не меняется:** production, API, данные и другие явно исключённые области
- **Baseline:** ссылка и commit/PR
- **Experiment:** ссылка и commit/PR
- **Compare states:** какие состояния сопоставлялись
- **Проверки:** desktop, Preview, Telegram/iPhone, ширины, safe areas, keyboard, reduced motion
- **Наблюдения:** только проверяемые факты
- **Интерпретация:** что эти факты могут означать; отделять от наблюдений
- **Решение:** принять / повторить / отложить / отклонить
- **Evidence:** ссылки на PR, скриншоты или отчёты без секретов и персональных данных
- **Следующий gate:** точное действие и ответственный
- **Rollback:** как удалить или отключить экспериментальный слой
