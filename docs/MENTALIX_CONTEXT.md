## 5. Решения владельца (не пересматривать без него)
«Сегодня» и карточки дня
- Две карточки: утренний чек-ин и разбор дня. Утро доступно весь день до 04:59, пока не пройдено (как Stoic). Разбор закрыт до времени разбора (по умолч. 19:00).
- Как у Stoic: непройденная карточка — тёмно-серая заливка без обводки, без картинки, подпись в 2 строки, заголовок с жирным словом, кнопка «Начать» (главная — светлая залитая, вторая — контурная). Пройденная — фон экрана, тонкая обводка, приглушённый текст, персонаж владельца стоит на тонкой линии.
- Картинки персонажа (красная рогатая маска, чёрное тело): утро — голова вправо, активный взгляд; вечер — закрытые «отдохнувшие» глаза. Никаких птиц Stoic и чужих рисунков.
- Ночь 00:00–04:59: тексты про «вчера». Тексты: «Как ты сегодня?», «Закрой этот день.», «Утро отмечено.», «День закрыт.», «Вернись к началу вчера.», «Подведи итог вчера.».
- Огонёк серии: всегда виден; при 0 — контур с залитым маленьким огоньком внутри, без цифры; при ≥1 — залит, внутренний огонёк «вырезан».
- Серия (как Stoic): день засчитывается за ЛЮБУЮ активность — чек-ин, отметка аскезы/ритуала, запись «Настроения». «Пройти заново» серию не увеличивает. Считает фронт; прошлые отметки практик — GET /api/practice-days (бэкенд #86).
- Календарь недели без галочек (#805). Вопрос владельцу «вернуть ✓ как у Stoic?» — открыт.
- Подсказки: закрываются крестиком или сами, когда пролистаны за экран (не исчезают во время прокрутки).
Чек-ин
- Утро: настроение → энергия → «Что на уме?». Шкалы без автоперехода: «Далее» + «Пропустить». «Эмоции» — вертикальный столбец pill, тяжёлая эмоция → mayak.
- Завершение разбора: «Сохранить» главная, «Разобрать со Следопытом» второстепенная.
Практики
- Аскезы/ритуалы — вариант C (#809): плитки в 2 колонки, отмеченная сегодня — светлая; без чисел и серий. Экран практики: крупная плитка-кнопка + «Зачем / Как / Заметка»; у аскезы «Сорвался сегодня». Тап отмечает: ритуал полным уровнем, аскеза «удержал».
- Практика «Настроение» — отдельная запись, видна в истории под чек-ином дня, засчитывается в серию.
- Практики по умолчанию новому аккаунту не добавляются.
Профиль и прочее
- Монохром; группы НАСТРОЙ → АККАУНТ → ПОМОЩЬ → ПРИЛОЖЕНИЕ; три баннера с персонажем. Поддержка — t.me/smira31.
- Заголовки экранов строчные с точкой: «твои практики.», «о тебе.», «подписка.».
- Масштаб приложения запрещён (щипок, двойной тап, автозум полей ввода).
- Жесты: свайп от левого края = «Назад» на вложенных экранах; шторки — свайп вниз. В Telegram без своего ✕ у шторки серии.

## 6. Опыт с агентами (важно)
- Новая задача = новый импорт Base44 («+» → Bring your own project → репо → ветка). Старый чат не переиспользовать — он складывает задачу в старую ветку/PR.
- Base44 сам называет ветки (fix-no-zoom, pr-preview-workflow…) — смотреть имя в отчёте.
- Агент кончился — новый импорт на ТОЙ ЖЕ ветке, промпт «продолжи, готовое не переделывай».
- Сообщения «Напишите continue» — владелец отвечает continue сам, ассистенту не несёт.
- Агенты врут про «предсуществующие» падения — проверять: в main 0 падений.
- Агенты путают номер PR — сверять ветку.
- Сборка в контейнере Base44 падает на top-level await в tgShell.js — это окружение; арбитр — Checks в PR. src/main.jsx и src/tgShell.js не трогать (CI запрещает).
- Тесты с жёстко зашитыми датами ломаются на следующий день — даты только относительно текущего дня.
- Агент может самовольно «улучшить» дизайн (нарисовал птицу Stoic) — в промпте запрещать менять то, что не просили.
- После деплоя в Telegram старая версия — очистить кэш Telegram.
