- Если нужного решения нет — задай ОДИН короткий вопрос, не додумывай.
- Если референса нет в репозитории и нет в чате — попроси владельца приложить скриншот/видео, укажи, какой экран и момент нужен.

## 4. Как мерить референсы (важно)
- Записи экрана iPhone владельца: 1 pt = 3 px кадра, ширина экрана 440 pt. (Старые кадры эталона 23.09: 1 pt = 1,5 px, ширина 393 pt.)
- Мерить по нескольким кадрам, никогда по кадру в момент нажатия/анимации — прежний ассистент дважды ошибся так (56 вместо 43, 14 вместо 21).
- Утверждённые значения: кнопка профиля 43×43 pt, чип огонька 62×43 pt, отступ от края 21 pt; карточки профиля: поля 16, скругление 16, строки 50 pt; фрейм приложения 440 px.

## 5. Решения владельца (не пересматривать без него)
- «Сегодня»: две карточки дня (утро и разбор), по времени: утро 05:00 → время разбора (по умолч. 19:00), разбор → до 04:59. Состояния active/locked/done/missed. В календаре недели галочек нет.
- Утренний чек-ин: настроение → энергия → «Что на уме?». Шкалы без автоперехода: белая «Далее» со стрелкой + «Пропустить» остаётся (как у Stoic). anxiety/focus не отправляются и не показываются, если не задавались.
- Шаг «Эмоции»: вертикальный столбец pill (EmotionStep), выбор обязателен, тяжёлая эмоция → переход mayak (и в чек-ине, и в практике).
- Завершение разбора: «Сохранить» главная, «Разобрать со Следопытом» второстепенная. ИИ-проводник — Следопыт.
- Огонёк серии виден всегда, скрыть нельзя; 0 — огонь без цифры. Серия = дни подряд с любой записью чек-ина (hasCheckinRecord). «Пройти заново» серию не увеличивает, без празднования. Серию считает фронтенд.
- Шторка серии в Telegram: без своего ✕, закрытие нативной «Назад».
- Практика «Настроение» — отдельная запись, чек-ин и серию не трогает. Её записи показывать в истории рядом с чек-ином дня.
- Практики по умолчанию новому аккаунту не добавляются.
- Заголовки экранов строчные с точкой: «твои практики.», «библиотека практик.», «о тебе.», «подписка.».
- Профиль: монохром; группы НАСТРОЙ → АККАУНТ → ПОМОЩЬ → ПРИЛОЖЕНИЕ → версия; в начале три баннера («Открой весь потенциал Mentalix», «Поддержи Mentalix», «Mentalix на сайте»). Поддержка — https://t.me/smira31 через openTelegramLink. Сайт — mentalix-production.web.app.
- Экран аскез/ритуалов: плитки в две колонки, отмеченная плитка инвертируется (тёмная → светлая), без чисел и серий в списке. Экран практики — вариант C: крупная плитка сверху (тап переворачивает), ниже раскрывающиеся «Зачем», «Как», «Заметка».

- Утро и разбор — одна запись за день; разбор ставит review_completed_at.

- Превью Base44 = dev-сервер с демо-данными и имитацией шапки Telegram (393/440); ?tgshell=0 — обычная веб-версия. Клавиатуру iOS и реальные данные не показывает.

- Base44 может назвать ветку по-своему — смотреть Files changed. Кнопку PR в Base44 самому не жать.
- Автосообщения Base44 об ошибке превью — не ответ; если агент остановился, отправить промпт заново.

- После деплоя старая версия — очистить кэш Telegram (Настройки → Данные и память → Использование памяти).
- Ошибка «о тебе.» на проде была из-за таймаута/сна Render, не из-за кода.
