# MXL-PRB-008 — Выгорание

- **Кластер:** D. Состояние и ресурс
- **Статус:** гипотеза; критерий пяти проблемных интервью (`PROBLEMS.md`) не закрыт
- **Дата:** 10.08.2026

## Как человек описывает проблему

- «Ничего не осталось, всё стало безразлично».

## Зафиксированные гипотезы (PROBLEMS.md)

Из «Первичной карты» [`PROBLEMS.md`](PROBLEMS.md): возможные причины — хроническая нагрузка, дефицит восстановления, конфликт требований; связанные принципы — `MXL-P002`, `P004`, `P006`; направление практики — оценка нагрузки, остановка эскалации, восстановление; главный риск — мотивировать через давление и пропустить необходимость специалиста; сигнал результата — снижается нагрузка и восстанавливается функционирование.

## Материал: научный обзор рецензируемой литературы (10.08.2026)

Вторичный материал по методу валидации, разрешённому обновлением [`MXL-DEC-007`](../core/PRODUCT_DECISIONS.md) от 10.08.2026 (уровень доказательности «научный обзор рецензируемой литературы» — PubMed, мета-анализы и систематические обзоры — отделён от более слабого уровня «анализ открытых источников»). Обзор подготовлен вне этой сессии Claude Code.

**Статус материала:** промежуточный. Не меняет статус проблемы, не меняет приоритет `MXL-PRB-008` в разделе «Предварительная приоритизация» [`PROBLEMS.md`](PROBLEMS.md) и не закрывает критерий пяти проблемных интервью (`MXL-RSCH-002`) — научный обзор рецензируемой литературы имеет более высокую доказательность, чем анализ открытых источников, но сам по себе не заменяет прямое пользовательское исследование и не даёт статус «проверено».

Находки:

1. **ВОЗ классифицирует выгорание как «оккупационный феномен», а не медицинский диагноз** — Международная классификация болезней (МКБ-11) явно определяет выгорание как результат хронического нерегулируемого рабочего стресса, а не как самостоятельное заболевание. Источник: официальная позиция Всемирной организации здравоохранения, 28.05.2019.
2. **Структурные изменения мозга при выгорании** — мета-обзор МРТ-исследований показывает измеримые структурные корреляты хронического выгорания. Источник: мета-обзор, PMC12429168, 2025 (1365 участников).
3. **Нарушение гипоталамо-гипофизарно-надпочечниковой (HPA) оси и регуляции кортизола** — хроническое выгорание сопровождается измеримой дисрегуляцией стрессовой гормональной оси. Источник: систематический обзор, PMC12641836, 2025.

Находка 1 напрямую усиливает уже зафиксированный в карточке риск «пропустить необходимость специалиста»: официальная позиция ВОЗ о том, что выгорание — не диагноз, не отменяет, а прямо предполагает необходимость медицинской/психологической помощи при выраженной картине, поскольку сам термин описывает клинически значимое истощение рабочего происхождения. Находки 2–3 детализируют физиологический механизм причины «хроническая нагрузка».

**Важно:** ни одна из находок не подтверждает, что немедицинская продуктовая практика способна лечить выгорание — только направление «оценка нагрузки, остановка эскалации» из уже зафиксированной строки `PROBLEMS.md`; граница эскалации к специалисту остаётся обязательной.

## Решение

Материал зафиксирован для дальнейшей проработки вертикали. Разработка функционала по `MXL-PRB-008` на основании одного этого материала не начинается — по `MXL-DEC-006` правило «до результата малого теста не разрабатывать отдельную функцию» для проблем вне `MXL-PRB-002` действует без изменений.
