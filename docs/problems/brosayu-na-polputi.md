# MXL-PRB-003 — Бросаю на полпути

- **Кластер:** B. Продолжение и завершение
- **Статус:** гипотеза; критерий пяти проблемных интервью (`PROBLEMS.md`) не закрыт
- **Дата:** 10.08.2026

## Как человек описывает проблему

- «Начинаю и быстро сливаюсь».

## Зафиксированные гипотезы (PROBLEMS.md)

Из «Первичной карты» [`PROBLEMS.md`](PROBLEMS.md): возможные причины — завышенный объём, отсутствие возврата, потеря смысла, истощение; направление практики — минимальная версия и протокол возврата; главный риск — требовать продолжать цель любой ценой; сигнал результата — растёт доля возвратов и завершённых минимумов.

## Материал: анализ открытых источников (10.08.2026)

Вторичный материал по альтернативному методу валидации, разрешённому обновлением [`MXL-DEC-007`](../core/PRODUCT_DECISIONS.md) от 10.08.2026 (расширение метода с `MXL-PRB-002` на `MXL-PRB-015`, `MXL-PRB-003`, `MXL-PRB-001`). Анализ открытых источников выполнен в чате Cowork (вне этой сессии Claude Code) 10.08.2026.

**Статус материала:** промежуточный. Не меняет статус проблемы, не меняет приоритет `MXL-PRB-003` в разделе «Предварительная приоритизация» [`PROBLEMS.md`](PROBLEMS.md) и не закрывает критерий пяти проблемных интервью (`MXL-RSCH-002`) — по `MXL-DEC-007` анализ открытых источников осознанно имеет более слабую доказательность, чем живые интервью, и сам по себе не даёт статус «проверено».

Находки:

1. **Точка остановки не случайна** — у разных людей разный паттерн (кто-то в «грязной середине», кто-то перед самым финалом).
2. **Частый триггер — угасание новизны:** старт даёт всплеск энергии, рутинная середина ощущается как труд без отдачи.
3. **«Serial starter» — устойчивый паттерн:** начинать легко, для завершения нужен отдельный навык.
4. **Рабочий воркэраунд** — сознательно «закрыть» проект упрощённой версией вместо того, чтобы бросать в подвешенном состоянии.

Находка 4 качественно совпадает с уже зафиксированным в `PROBLEMS.md` направлением практики «минимальная версия и протокол возврата». Находки 1–3 (неслучайность точки остановки, угасание новизны как триггер, завершение как отдельный навык) — новый угол, детализирующий причину «отсутствие возврата»/«потеря смысла», не отражённый в текущей строке таблицы; в таблицу `PROBLEMS.md` не добавлены, чтобы не менять формулировку проблемы без отдельного решения.

## Решение

Материал зафиксирован для дальнейшей проработки вертикали. Разработка функционала по `MXL-PRB-003` на основании одного этого материала не начинается — по `MXL-DEC-006` правило «до результата малого теста не разрабатывать отдельную функцию» для проблем вне `MXL-PRB-002` действует без изменений.
