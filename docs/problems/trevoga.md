# MXL-PRB-007 — Тревога

- **Кластер:** D. Состояние и ресурс
- **Статус:** гипотеза; критерий пяти проблемных интервью (`PROBLEMS.md`) не закрыт
- **Дата:** 10.08.2026

## Как человек описывает проблему

- «Не могу перестать прокручивать».

## Зафиксированные гипотезы (PROBLEMS.md)

Из «Первичной карты» [`PROBLEMS.md`](PROBLEMS.md): возможные причины — неопределённость, перегрузка, угроза, физическое состояние; связанные принципы — `MXL-P002`, `P007`; направление практики — заземлить факты и выбрать безопасную зону влияния; главный риск — выдать поддержку за лечение; сигнал результата — уменьшается интенсивность либо яснее следующий безопасный шаг.

## Материал: научный обзор рецензируемой литературы (10.08.2026)

Вторичный материал по методу валидации, разрешённому обновлением [`MXL-DEC-007`](../core/PRODUCT_DECISIONS.md) от 10.08.2026 (уровень доказательности «научный обзор рецензируемой литературы» — PubMed, мета-анализы и систематические обзоры — отделён от более слабого уровня «анализ открытых источников»). Обзор подготовлен вне этой сессии Claude Code.

**Статус материала:** промежуточный. Не меняет статус проблемы, не меняет приоритет `MXL-PRB-007` в разделе «Предварительная приоритизация» [`PROBLEMS.md`](PROBLEMS.md) и не закрывает критерий пяти проблемных интервью (`MXL-RSCH-002`) — научный обзор рецензируемой литературы имеет более высокую доказательность, чем анализ открытых источников, но сам по себе не заменяет прямое пользовательское исследование и не даёт статус «проверено».

Находки:

1. **Сниженная функциональная связность миндалина–префронтальная кора при генерализованном тревожном расстройстве (ГТР)** — ослабленная регуляторная связь между этими областями сопровождает трудность произвольно остановить тревожное «прокручивание». Источник: систематический обзор, _NeuroImage: Clinical_, 2019, идентификатор S2213158219303663.
2. **Общая нейросеть страха задействована при разных тревожных расстройствах** — данные подтверждают частично общий нейронный субстрат тревоги и страха, а не изолированные механизмы для каждого расстройства. Источник: Etkin & Wager 2007, _American Journal of Psychiatry_, PubMed 17898336.
3. **Структурная специфика именно ГТР** — при этом есть и отличительные структурные особенности, не сводящие ГТР к общей тревожной сети. Источник: _Translational Psychiatry_, PMC9508096.

Находка 1 детализирует причину «неопределённость»/«угроза» в текущей строке `PROBLEMS.md`: показывает нейронный механизм, почему заземление фактов (уже зафиксированное направление практики) может опираться на компенсацию сниженной регуляторной связи. В таблицу не добавлена, чтобы не менять формулировку проблемы без отдельного решения.

**Важно:** находки описывают клинически диагностированное ГТР, а не бытовую тревогу в целом; это усиливает уже зафиксированный в карточке риск «выдать поддержку за лечение» и границу «Mentalix не определяет и не лечит» из общего шаблона карточек.

## Решение

Материал зафиксирован для дальнейшей проработки вертикали. Разработка функционала по `MXL-PRB-007` на основании одного этого материала не начинается — по `MXL-DEC-006` правило «до результата малого теста не разрабатывать отдельную функцию» для проблем вне `MXL-PRB-002` действует без изменений.
