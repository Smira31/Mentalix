# Карта проблем пользователя Mentalix

**Версия:** 0.1.0
**Статус:** рабочая карта; приоритеты являются продуктовыми гипотезами до пользовательского исследования.

## Нормативное правило

```text
проблема пользователя → принцип → практика → контент → источник
```

Mentalix начинает с формулировки человека, а не с книги, автора или функции приложения. Одна проблема может иметь несколько механизмов, поэтому карта не используется для медицинской диагностики. Полная карточка создаётся по [`problem_template.md`](problem_template.md).

## Научный обзор литературы 10.08.2026

Для 11 проблем (`MXL-PRB-004`, `005`, `006`, `007`, `008`, `009`, `010`, `011`, `012`, `013`, `014`) подготовлены отдельные карточки по [`problem_template.md`](problem_template.md) на основе научного обзора рецензируемой литературы (PubMed, мета-анализы, систематические обзоры) — более строгого уровня доказательности, чем анализ открытых источников. Оба уровня доказательности и их статус объяснены в обновлении [`MXL-DEC-007`](../core/PRODUCT_DECISIONS.md#mxl-dec-007--разрешить-персональный-пилот-после-интервью-владельца) от 10.08.2026.

Научный обзор поддерживает гипотезы о механизме проблемы и границы эскалации к специалисту. Он **не заменяет** проблемные интервью и не изменяет статус проблем в этой карте: приоритеты и статус остаются продуктовыми гипотезами до пяти проблемных интервью на проблему, как и было зафиксировано в «Решении v0.1» ниже.

## Решение v0.1

- Первый кластер для проверки: **A. Запуск действия**.
- Первая вертикаль: [`MXL-PRB-002 — Не могу начать`](ne-mogu-nachat.md); содержательное review пройдено, следующий ворот — пять проблемных интервью.
- Следующие кандидаты после проверки вертикали: [`MXL-PRB-015`](peregruzka.md), [`MXL-PRB-003`](brosayu-na-polputi.md), затем [`MXL-PRB-001`](prokrastinaciya.md).
- Перед изменением рейтинга провести минимум пять проблемных интервью и проверить формулировки на продуктовой аналитике без записи личных текстов.
- Для всех трёх кандидатов 10.08.2026 зафиксирован промежуточный материал анализа открытых источников (по расширению `MXL-DEC-007` на эти три проблемы) — приоритет и статус не изменены, критерий пяти интервью не закрыт.
- Для остальных одиннадцати проблем карты (`MXL-PRB-004`, `005`, `006`, `007`, `008`, `009`, `010`, `011`, `012`, `013`, `014`) 10.08.2026 зафиксирован промежуточный материал научного обзора рецензируемой литературы (PubMed, мета-анализы и систематические обзоры) — более высокий уровень доказательности, чем анализ открытых источников (`MXL-DEC-007`, обновление 10.08.2026). Приоритет и статус не изменены, статус «проверено» не присваивается, критерий пяти проблемных интервью не закрыт ни для одной из них.
