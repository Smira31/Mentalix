# Индекс документации Mentalix

Этот индекс перечисляет каждый Markdown-файл в `docs/`. Метаданные `status` и `last_verified` находятся в frontmatter каждого документа. Статусы означают: `normative` — обязательный источник; `current` — актуальное подтверждённое состояние; `working` — рабочий материал; `historical` — сохранённая история; `archived` — архив.

## Канонические точки входа

| Слой | Файл | Зачем открывать |
|---|---|---|
| Вход | [`INDEX.md`](INDEX.md) | Открыть для полного каталога документации и статусов. |
| Вне docs | [`AGENTS.md`](../AGENTS.md) | Открыть для базовых правил и общего контекста репозитория. |
| Вне docs | [`README.md`](../README.md) | Открыть для базовых правил и общего контекста репозитория. |
| Вне docs | [`PROJECT_BRIEF.md`](../PROJECT_BRIEF.md) | Открыть для базовых правил и общего контекста репозитория. |
