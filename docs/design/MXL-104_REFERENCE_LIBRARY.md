# MXL-104 — Mentalix reference library

The library is a source-of-truth index, not a random moodboard. Each reference record contains `reference_id`, title, source URL or owned asset path, capture date, category, approved use, rejected use, license/rights note, related token and reviewer status.

| Category | Use |
| --- | --- |
| layout | hierarchy, spacing and responsive composition |
| typography | measure, scale and label/body distinction |
| motion | duration, easing and reduced-motion alternative |
| illustration | tone, metaphor and accessibility text |
| Telegram | native container affordances and safe-area patterns |

A reference becomes approved only after rights, relevance, accessibility and Mentalix fit are recorded. External brands are references, not assets to copy. Deprecated items remain in history with a reason; they are not silently deleted.
