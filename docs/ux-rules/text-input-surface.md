# Правило текстового ввода Mentalix

Во всех интерфейсах Mentalix, где пользователь должен вводить текст, поле автоматически получает фокус при открытии экрана, а клавиатура iOS открывается сразу. Панель действий редактора (`+`, `Aa`, действие углубления и круглая стрелка отправки) должна располагаться непосредственно над клавиатурой через visual viewport и сохранять фокус после отправки.

Экран ввода должен использовать максимально доступную высоту: верхние кнопки «Назад» и «Закрыть» остаются в верхнем safe area, заголовок и подсказка поднимаются вверх, размер заголовка соответствует reference-экрану, а поверхность редактора не создаёт серую карточку поверх чёрного фона, если это не предусмотрено конкретным reference.

Для Check-In финальные варианты полезности используют визуальные hand-иконки и русские подписи: «Нет», «Немного», «Да».
