# Mentalix — Stoic feature decisions

## Отмена анти-streak решения

Историческое решение «не показывать streak как давление, а показывать непрерывность Пути» **отменено владельцем 20.09.2026** в рамках `MXL-STREAK-CHECKIN-001` (экран завершения утреннего чек-ина, PR #694). Mentalix использует классическую механику серии: число последовательных дней, начиная с 1 после первого завершённого чек-ина. Это не меняет тон текстов: интерфейс не должен стыдить пользователя, угрожать потерей серии или превращать её в обязательство.

История исходного решения сохранена в архивном документе; этот addendum является актуальным продуктовым решением для streak-экрана.
